{% endset %} {# SECTION 2: FEATURES #} {% set section2Html %}

Explore the core features driving this prototype.

  • Smart evidence marking
    Features that allow a user to read or unread, flag or unflag files related to the case. These status' are visible only to the user.
  • Filters
    Three filters enhanced upon from NSIP, MoJ, and Appeals services that apply to short or long filter lists.
  • Dynamic cards
    Dynamically add summary cards and anchor links to a case details page when adding data from an add to list pattern.
  • Audit log
    Track details of every change made to your case in a table, labelling the time and date and which user made the change.
  • Success banner
    Success banner with an anchor link to jump straight to the section you edited.
  • Working draft array
    Add to list array logic to mimic how data is handled in dev enivronments, enforcing the user to save data to the database before it appears on the case.

{# ========================================================== #} {# TAB 3: BUGS #} {# ========================================================== #}

Bugs and issues

  • Live deployed prototype issues

    Reported on 4 March 2026

    If you create data on the prototype and leave it for 5 minutes, any new data you create will not persist. This issue is related to Azure session management. If you clear the data at manage-prototype/clear-data, you can start the session fresh and the service will work as intended.

    Azure
  • Live deployed prototype issues

    Fixed on 4 March 2026

    There are currently ongoing issues with the live deployed prototype. This issues are known to persist only on the deployed version — Local hosting works as intended:

    • Data being cleared when filling in the 'create a case' flow.
    • Data not persisting correctly in some browser sessions.
    • The generation of wrong reference codes when creating a new case.
    • Clearing of cases when more than two cases have been created.
    Fixed
  • Live deployed prototype issues

    Fixed on 3 March 2026
