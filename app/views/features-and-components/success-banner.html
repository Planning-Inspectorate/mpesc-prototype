Success banner

Success banners confirm to the user that an action has been completed, featuring a dynamic anchor link to jump straight to the edited section.

When to use this feature

Use this component immediately after a user:

  • saves data from an "Add to list" pattern
  • adds, updates, or removes an item in a complex array

This pattern helps improve the user experience by:

  • providing immediate reassurance that their action was successful
  • reducing scroll fatigue by allowing them to jump straight back down to the exact summary card they were interacting with

How to implement

  1. When a user saves an update in a sub-route, set req.session.flashSection to the exact `id` of the HTML element you want the user to anchor to on the main page (e.g., "site-address").
  2. Redirect the user back to the main case details hub.
  3. The case-details.js router will catch the variable, pass it to the Nunjucks template as flashSection, and immediately wipe it from the session so the banner doesn't persist if the user refreshes the page.
  4. The Nunjucks template detects the flashSection variable, triggers the banner, and injects the ID directly into the href="#{{ flashSection }}" anchor link.
