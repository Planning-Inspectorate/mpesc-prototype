Dynamic cards

Dynamically add summary cards and anchor links to a case details page when adding an unpredictable amount of data from an "Add to list" pattern.

When to use this feature

Use this component when a user needs to collect and display an array of multiple items on the case dashboard, such as:

  • Adding multiple outcomes or decisions
  • Assigning multiple inspectors to a single case
  • Logging a list of objectors or third-party contacts

This pattern helps structure the front-end by:

  • generating a new summary card automatically for every item in an array
  • giving each card a unique HTML ID (e.g. id="outcome-1") so success banners can anchor directly to them
  • keeping the main overview card clean by only displaying a bulleted list summary of the added items

How to implement

  1. In your routing logic, use the "Working Draft Array Pattern" (seen in the Routes tab) to collect multiple items into a temporary array (e.g. req.session.data['tempOutcomesList']).
  2. When the user clicks save, commit the array to the main case object (e.g. c.outcomes) and redirect back to the case details dashboard.
  3. On the front-end view, check if the array exists using {% raw %}{% if currentCase.outcomes.length > 0 %}{% endraw %}.
  4. Use a Nunjucks {% raw %}{% for outcome in currentCase.outcomes %}{% endraw %} loop to wrap a standard GOV.UK Summary Card, which will dynamically clone the component for every item saved in the list.
  5. Crucial: Append loop.index to the end of your card's ID (e.g., id="outcome-{% raw %}{{ loop.index }}{% endraw %}"). This ensures every dynamically generated card has a unique HTML identifier, allowing your success banner anchor links to scroll down to exactly the right place.
