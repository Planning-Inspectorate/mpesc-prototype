Audit log

Track details of every change made to your case in a table, labelling the time and date and which user made the change.

When to use this feature

Use this component to maintain a transparent, chronological history of case modifications. It should be updated immediately after a user:

  • creates a new case or uploads documents
  • changes the status of a case
  • adds, updates, or removes contacts or data from a list

This pattern helps improve the user experience and service integrity by:

  • recording exactly when an action happened
  • showing who made the change for accountability
  • providing a clear timeline of events for auditing purposes

How to implement

  1. Ensure the addAuditLog helper is present in your helpers.js file and properly exported at the bottom of the script.
  2. At the top of your routing file, import the helper: const { addAuditLog } = require('../helpers');
  3. Inside your POST route, immediately after successfully pushing or saving data to the case, call the helper: addAuditLog(req, ref, "Description of the change");.
  4. On the front-end view, map the pagedLogs (or currentCase.auditLog) array into the table component. Use the | safe filter on the date output so the HTML line-breaks render correctly.
