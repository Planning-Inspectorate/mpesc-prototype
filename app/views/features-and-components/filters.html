Filters

Use filters to help users narrow down a list of results. There are 3 common filter layouts in this prototype. Choose the one that best meets user needs and the context of the page.

When to use filters

Use filters when users need to:

  • narrow down a long list of results
  • find specific items based on known criteria
  • combine filters with search to refine results
