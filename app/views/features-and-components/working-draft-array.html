Working draft array pattern

A backend routing pattern for handling multi-step "Add to list" forms without corrupting the main database.

When to use this feature

Use this architectural pattern whenever you are building an "Add to list" journey (e.g., adding Inspectors, Linked cases, or Outcomes to a case). It solves a critical problem in prototyping:

  • If a user starts adding a complex item but abandons the form halfway through, we do not want half-finished data polluting the main case object.
  • If a user edits an existing list, deletes an item, but then clicks "Cancel", we need a way to restore the original list perfectly.

This pattern protects your data by isolating the changes in a temporary "Draft" array. Changes are only committed to the real case data when the user explicitly clicks "Save".

Boilerplate templates

You can copy and paste the code below to instantly start up a new Add to list journey. This uses linked-cases as the primary example, but you can find and replace it with your feature (e.g. inspectors).

Understanding the flow

  1. Start: The user clicks "Add or Edit items" on the dashboard. The `start` route clones the real case data into a temporary session array called tempLinkedCasesList.
  2. Hub: The Hub page renders the contents of tempLinkedCasesList inside a table.
  3. Add/Edit: When a user adds a new item or edits an existing one, the changes are saved to an isolated tempLinkedCase object.
  4. Save Item: When the user submits the individual form, the tempLinkedCase is pushed (or replaced) into the tempLinkedCasesList array. The user is bounced back to the Hub page.
  5. Cancel & Remove (Safety Nets): The cancel and remove pages act as necessary safety nets. They should be presented if the user has changed something in their session (or is about to delete an item) without saving first, preventing accidental deletions or loss of unsaved work.
  6. Commit: Only when the user clicks "Save and continue" on the Hub page does the final route overwrite the real case data with the contents of the draft array.
